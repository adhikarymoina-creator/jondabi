# Bangla Citizen Voice

Recreate the provided reference site https://jondabi-civic-tech-p-r7ih.bolt.host/ as a new Bangla civic-demands platform. Apply these required updates: hero headline must be exactly “আপনার এলাকার উন্নয়নের দাবি জানান আজই”, significantly larger and bold/prominent. Add a complete Bangladesh 4-level cascading location filter in the header/search area: Division (বিভাগ), District (জেলা), Upazila (উপজেলা), Union (ইউনিয়ন). Include a structured Bangladesh location dataset covering all 8 divisions, 64 districts, 495 upazilas, and unions as comprehensively as feasible; cascading selections must filter each subsequent dropdown. Connect selections at any level to filter the civic demands list shown on the homepage. Match the reference site's overall product intent and visual feel, but do not copy branding or assets verbatim.
